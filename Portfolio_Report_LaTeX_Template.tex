% Section 1 paragraph
\newcommand{\MethodologyText}{%
From the 30-stock NSE universe, we ranked stocks by annualised Sharpe ratio (RF = 6.5\%) and selected the top 10 for portfolio construction. For this dataset (739 trading days), this screening produced a diversified set across 7 sectors with predominantly low-to-moderate pairwise correlations (average correlation $\sim$0.30), and delivered strong GMV/MSR outcomes (Sharpe 1.7540 and 1.9049). Compared with a sector-constrained top-pick baseline designed to maximize diversification, this approach improved Sharpe for both optimized portfolios (GMV +0.4007, MSR +0.0476). These observed results support this as a robust method for this experiment.%
}
