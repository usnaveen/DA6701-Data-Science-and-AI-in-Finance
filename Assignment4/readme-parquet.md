# Parquet Artifact Guide

This note explains the parquet files generated by `Assignment4/p1d1.ipynb` and when to use each one.

## Main Files

- `p1d1_model_ready_returns.parquet`
  - Combined return matrix for the final usable stock universe plus the benchmark column `^GSPC`.
  - Shape at generation time: `1507 x 554`
  - Use this when you want one file containing both predictors and benchmark returns.

- `p1d1_stock_returns.parquet`
  - Stock-only log return matrix.
  - Contains the `553` usable constituent stocks.
  - Use this when your model expects only stock returns as features.

- `p1d1_benchmark_returns.parquet`
  - Benchmark-only return series for `^GSPC`, saved as a one-column dataframe.
  - Use this as the target/benchmark series in tracking error or portfolio replication methods.

## Split Files

- `p1d1_train_returns.parquet`
  - Date range: `2020-01-03` to `2024-12-31`
  - Contains stocks plus `^GSPC`
  - Use for model fitting and stock-selection logic

- `p1d1_val_returns.parquet`
  - Date range: `2025-01-02` to `2025-06-30`
  - Contains stocks plus `^GSPC`
  - Use for tuning and comparing candidate methods

- `p1d1_test_returns.parquet`
  - Date range: `2025-07-01` to `2025-12-31`
  - Contains stocks plus `^GSPC`
  - Use only for final holdout evaluation

## Universe and Audit Files

- `p1d1_kept_universe.parquet`
  - Metadata for stocks kept in the candidate universe before the final training-gap check.
  - Includes each ticker's first date, last date, and row count.

- `p1d1_excluded_universe.parquet`
  - Metadata for coverage-based exclusions.
  - Reasons include `late_entry` and `early_exit`.

- `p1d1_final_prices.parquet`
  - Final price matrix used before return computation.
  - Useful if someone wants to recompute returns differently later.

## CSV Companion Files

- `p1d1_summary.csv`
  - Small summary table with counts, date ranges, and split sizes.

- `p1d1_file_issues.csv`
  - Files excluded immediately because they were empty or not price histories.

- `p1d1_train_gap_exclusions.csv`
  - Stocks removed after coverage filtering because they still had missing training-period prices.

## Suggested Team Usage

- `P1`
  - Use `p1d1_model_ready_returns.parquet` and `p1d1_summary.csv` for data handoff and checks.

- `P2` and `P3`
  - Use `p1d1_train_returns.parquet`, `p1d1_val_returns.parquet`, and `p1d1_test_returns.parquet`.
  - Split `^GSPC` out as the benchmark target and use the remaining columns as stock returns.

- `P4`
  - Use `p1d1_val_returns.parquet` and `p1d1_test_returns.parquet` for evaluation runs.
  - Use `p1d1_benchmark_returns.parquet` if a separate benchmark file is more convenient.

## Loading Example

```python
import pandas as pd

train = pd.read_parquet("p1d1_train_returns.parquet")
X_train = train.drop(columns="^GSPC")
y_train = train["^GSPC"]
```
